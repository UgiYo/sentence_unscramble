# 英文句子拆解打亂工具

這是一個純前端網頁工具，可輸入題數與英文句子，並輸出打亂排序的單字與填空題目。

## 使用方式

### 一般使用者：直接用滑鼠點擊

不需要輸入任何指令，也不需要安裝 Node.js。

1. 下載或打開此資料夾。
2. 用滑鼠雙擊 `點我開啟.html`。
3. 瀏覽器開啟後即可開始輸入題數、英文句子並產生學生作答頁。

> 如果電腦沒有顯示副檔名，也可以雙擊 `index.html` 直接使用。

### 開發者：使用本機伺服器

如果需要用本機伺服器測試，再安裝 Node.js 18 或更新版本，並執行：

```bash
npm start
```

開啟終端機顯示的網址，預設為 <http://127.0.0.1:4173/>。

## 功能

- 輸入題數後自動產生對應數量的句子輸入欄位。
- 將英文句子拆成單字，保留一個提示字，其他單字以 `/` 分隔並隨機打亂。
- 產生填空題目，例如：`題目：_____ weather _____ _____ _____`。
- 可套用 10 題範例、清除內容，以及複製輸出結果。
- 出題後可產生「學生作答頁」，依題號排序顯示題目，不顯示原始英文句子，方便列印給學生作答。

## 開發檢查

```bash
npm run check
```
